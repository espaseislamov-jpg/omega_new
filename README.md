# Omega V3.0

Обработка хроматограмм FID из CSV: поиск и разделение пиков, расчёт площадей и
индекса, ручная корректировка границ и выгрузка результатов серии.

Эта версия **без проверки лицензии, срока действия и серверного времени**.
Судья алгоритмический. Нейросетевые модели и обучение модели не включены.

## Запуск из исходников — Windows x64

Нужен Python 3.14 с Tkinter. Из корня проекта:

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\run_omega.cmd
```

После установки зависимостей для работы интернет не требуется. `run_omega.cmd`
использует локальную `.venv`, а при её отсутствии — Python из PATH. При запуске
лаунчер проверяет версии библиотек и при необходимости устанавливает зависимости
из `requirements.txt`. Закреплённые версии нужны для воспроизводимости расчёта.

Вводная обучалка появляется один раз, затем доступна по кнопке «Как работать».
Её отметка хранится в `%LOCALAPPDATA%\Omega\ui\tutorial_v3_seen`.

## Работа

1. Нажмите «Новый расчёт», выберите профиль прибора и CSV.
2. Проверьте отмеченные судьёй пробы. При необходимости задайте границы вручную
   и примените их. ПКМ на графике позволяет добавить пик.
3. Откройте «Результаты серии» и скопируйте таблицу в шаблон.

Базовые профили **FID2 (119)** и **FID1 (128)** включены в программу со своими
настройками. Профиль 118 сохранён для совместимости. Профили можно настраивать,
копировать и импортировать; пользовательские настройки сохраняются в
`omega_instrument_profiles.json` рядом с программой.

Квиз при выходе необязательный: он собирает ручные оценки пиков и сохраняет
`*.omega-quiz` в `judge_workspace\quiz_outbox` рядом с программой. Импорт ответов
доступен в меню «Обучение». Нейросудья от этого автоматически не включается.
Исходные пробы, пользовательские настройки и собранные оценки в Git не входят.

## Сборка EXE и установщика

На Windows в том же окружении:

```powershell
.\.venv\Scripts\python.exe scripts\build_omega_v2.py --skip-deps
```

Результат: `dist\Omega_V3.0\Omega.exe`. Для переносимой версии копируйте всю
папку `Omega_V3.0`, включая `_runtime_v3_0_1_open`. Отдельный каталог библиотек
предотвращает смешение зависимостей со старыми установками.

Для создания установщика установите Inno Setup 6 и выполните:

```powershell
ISCC.exe installer\omega_v2.iss
```

Получится `installer_output\Omega_V3.0_Setup.exe`; Python на компьютере
пользователя не нужен. Установщик сохраняет профили, ручные правки и ответы квиза.

В репозитории оставлены исходники приложения, ресурсы расчёта, зависимости и
файлы сборки. Эксперименты, старые EXE, отчёты и рабочие данные исключены.
